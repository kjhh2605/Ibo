Human head-mask annotation

AI drafts are not ground truth. Select each frozen image. For positives, click a polygon enclosing every face, ear, hair and hat pixel, including loose hair; close it with Fill polygon. Add more polygons if necessary. Erase starts the annotation again. Negatives require explicit classification review, not a fabricated mask. The actual reviewer must inspect every edge at full resolution; the annotator may also be the reviewer.

This page stays local. It does not upload images. Start python3 -m http.server --bind 127.0.0.1 --directory verification/fixtures 8767 from repository root; open http://127.0.0.1:8767/review/. Review item masks.
