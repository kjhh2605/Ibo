# 나만의 길거리 피팅 앱: 구현 가능성 조사와 MVP 기능 합의

상태: 초안

## 목표와 배경

메타에서 주최하는 해커톤에서, 쇼핑 중 보았던 옷을 다시 찾아 자신에게 어울리는지 미리 확인하는 애플리케이션을 기획한다. 빈티지 숍을 비롯해 자체 가상 피팅 서비스를 제공하지 않는 의류 매장에서도 특정 브랜드에 종속되지 않고 사용할 수 있는 경험을 지향한다.

여러 매장을 돌아다닌 뒤 이전에 본 옷이 마음에 들어도 어디서 판매했는지 다시 찾기 어려운 문제를 해결한다. 휴대폰 GPS로 관심 의류와 판매 위치를 연결해 기록하고, 나중에 해당 옷을 선택하면 판매 위치까지 돌아가는 경로를 안내한다. 가상 피팅으로 스타일을 확인하는 경험과 실제 매장을 다시 찾아가는 경험을 연결하는 것이 목표다.

외부 가상 피팅 서비스에 개인 사진을 제공할 때 발생할 수 있는 개인정보 노출 우려를 고려하여, 개인 사진은 기기 안에서만 처리하고 서버로 전송하지 않는다.

## Astra에 맡길 범위

메타가 제공하는 모델과 아래 기획의 구현 가능성을 조사하고, 조사 결과를 바탕으로 사용자와 MVP 제작을 위한 기능 범위를 합의한다. 현재 요청 범위는 조사와 기능 합의이며, 앱 제작 자체는 이후 목표다.

## 구상한 사용자 경험

1. 쇼핑하면서 메타글래스로 보았던 장면을 기록한다.
2. 앱에서 쇼핑 과정을 담은 영상을 되돌려 보다가 원하는 장면에서 일시정지하고, 그 장면의 특정 옷을 지정한다. “거기 있는 파란색 옷”처럼 자연어로 관심 상품을 지정하는 방식을 포함한다.
3. 사용자가 직접 사진을 자르거나 수정하지 않아도 AI가 해당 의류를 식별하고 추출한다.
4. 사용자가 자신의 사진을 업로드하거나 앱에서 직접 촬영하고, 이미지 생성 기능으로 선택한 옷을 입은 자신의 모습을 가상 피팅으로 확인한다. 업로드는 앱으로 사진을 가져오는 입력 방식이며, 사진의 서버 전송 금지 조건은 유지한다.
5. 자신이 가지고 있는 옷과 새로 본 상품을 매칭해 스타일을 미리 확인한다.
6. 휴대폰 GPS를 사용해 보았던 옷과 판매 위치를 연결해 기록하고, 나중에 그 옷이 마음에 들면 현재 위치에서 판매 위치까지 내비게이션처럼 이동 경로를 안내한다.

위 내용은 전체 제품 구상이다. 휴대폰 GPS를 활용한 판매 위치 기록과 경로 안내, 녹화는 필요한 기능이며, 구체적인 MVP 구현 범위는 아래 전제와 검토 사항을 바탕으로 합의한다.

## 현재 제작 전제

- AI 모델은 메타가 제공하는 모델만 사용한다. 구현 가능성 조사와 MVP 기능 제안도 이 제약을 따른다.
- 개인 사진은 기기 안에서만 처리한다. 직접 관리하는 서버를 포함해 서버 전송은 허용하지 않는다.
- MVP는 Android 스마트폰 앱을 대상으로 하며, 모든 사진 처리와 AI 모델 실행은 휴대폰 안에서 수행한다. 구체적인 기종은 미정이다.
- 실제 메타글래스를 보유하고 있지 않으므로 우선 애플리케이션만 제작하는 것을 목표로 한다.
- 앱 시연의 비전 입력은 임시 사진/영상으로 대체한다.
- 제품 기능에는 녹화를 포함하며, 촬영·녹화는 별도 모듈로 분리한다. 실제 글래스 촬영은 우선 휴대폰 촬영으로 대체하는 방향이다. MVP에서 임시 사진과 휴대폰 촬영을 어떻게 자연스럽게 연결할지는 검토 중이다.
- 사진 속 대상을 자연어 또는 채팅으로 지정하고, 대상을 추출한 뒤 이미지를 생성하는 경험을 구현하고 싶다. 음성 입력까지 포함할지는 미정이다.

## 조사하고 검토할 내용

### 우선 검토할 MVP 흐름

사용자가 채택한 우선 검토안이며, 구현 확정안은 아니다.

쇼핑 기록 시작 → 휴대폰 녹화와 GPS 기록 → 쇼핑 영상 다시 보기 및 일시정지 → 해당 장면에서 옷 선택 → 가상 피팅 → 판매 위치로 길 안내.

임시 사진도 동일한 쇼핑 기록 화면에서 다루어, 시연 입력과 휴대폰 촬영 입력이 같은 사용 흐름으로 이어지도록 검토한다.

라벨링 UX의 우선 검토안은 다음과 같다. 사용자가 일시정지한 장면에서 옷을 탭하거나 채팅으로 지정하면, 선택한 옷만 강조하고 라벨을 표시한다. 라벨의 세부 내용과 저장 방식은 이후 구체화한다.

### 구현 가능성 조사

- 메타 제공 모델 중 자연어로 지정한 의류의 식별·분류·추출에 활용할 수 있는 모델과 실제 지원 범위. 
- 추출된 의류를 이용한 이미지 생성 및 가상 피팅의 구현 가능성, 이에 필요한 모델과 입력 자료.
- 메타글래스의 촬영·기록과 앱 연동 가능성. 현재 구상에서 가정한 기능을 실제 지원 여부와 구분한다.
- 임시 사진 기반 시연과 별도 촬영·녹화 모듈을 연결하는 자연스러운 MVP 사용 흐름을 제안한다. 휴대폰 촬영으로 글래스를 대신하는 방식과 녹화 영상에서 분석할 사진으로 이어지는 흐름을 검토한다.
- 개인 사진을 서버로 전송하지 않고 기기 내에서 대상 추출과 가상 피팅을 처리할 수 있는지, 필요한 실행 환경과 한계. 쇼핑 기록의 개인정보 노출 우려를 고려할 처리 방식도 검토한다.
- 휴대폰 GPS로 옷의 판매 위치를 기록하고 해당 위치까지 내비게이션 방식으로 경로를 안내하는 구현 방식. 앱 내 안내와 외부 내비게이션 연동 중 구현 방식, 전체 쇼핑 동선 기록의 필요성, 위치의 세밀함은 검토한다.
- 보유 의류와의 매칭의 구현 가능성과 MVP 포함 여부.
- 영상의 일시정지 장면에서 탭 또는 채팅으로 지정한 옷만 강조하고 라벨을 표시하는 UX의 구현 가능성과 세부 동작을 검토한다.

## 원하는 결과

- 제안한 경험을 어떤 모델과 방식으로 구현할 수 있는지에 대한 조사 결과.
- 실제 글래스 없이 임시 데이터로 시연할 수 있는 범위와 이후 실제 연동이 필요한 부분의 구분.
- 사용자와 합의한 MVP 기능 범위 및 남은 미정 사항.
