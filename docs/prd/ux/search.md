# 사진 검색과 후보 선택

상태: 인터뷰 R9까지 반영, 화면 배치는 프로토타입 세션에서 확정

근거: [decisions.md](../decisions.md) D-R3-01~11, D-R7-09. 구현 계약: [agent-tools](../contracts/agent-tools.md), [relay-api](../contracts/relay-api.md), [device-modules](../contracts/device-modules.md), [data-model](../contracts/data-model.md). 전송 범위는 [privacy](../product/privacy.md)를 따른다. 기존 화면 중 후속 결정과 충돌하지 않는 문구만 유지한다(D-R1-03).
추가 근거: D-R9-02(바로 자른 가게 옷 이름), D-R9-04(Visit 제거·Trip 통합).

## F-06 에이전트 사진 검색

- **우선순위:** P0(D-R3-01).
- **화면:** "Find it". 홈·저장한 옷의 "Find another"·Trip에서 진입한다. 어느 진입점에서도 검색 대상은 모든 trip이며 오늘이나 현재 가게만으로 고정하지 않는다. 별도 가게 화면은 없다(D-R3-03, D-R9-04).
- **동작:** 질의 말풍선 → 도구 단계 순차 표시 → 결과 카드 → F-08 선택. 결과가 나오면 단계를 한 줄로 접고 탭하면 다시 펼친다(D-R3-09).

### 기능 규칙과 상태(확정)

| 상태 | 가능한 동작·제한 | 근거 |
| --- | --- | --- |
| 입력 전 | 영어 텍스트 또는 F-07 음성. 모든 trip을 검색 대상으로 삼음 | D-R0-02, D-R3-03, D-R3-05 |
| 진행 중 | 앱이 도구 루프를 실행. 릴레이가 질의당 Spark 4회와 SAM 사진 합계 3장을 강제. 한도를 늘려 계속 호출하지 않음 | D-R1-02, D-R3-01 |
| 방문 요약 | trip/가게 순서·시간·외관 설명·메모를 사용. 좌표·이미지 없이 요약을 Spark로 전송 | D-R3-03, D-R3-04 |
| 결과 있음 | 사진 카드를 탭해 후보 선택. 단계는 한 줄 요약으로 접으며 다시 펼칠 수 있음 | D-R3-09 |
| 못 찾음·기록 없음 | 못 찾았음을 알리고 다시 질문 또는 Trips → Trip → Pick 직접 탐색. Trip의 가게별 사진을 바로 선택하며 범위 칩·Visit은 없음 | D-R3-06, D-R9-04 |
| API 실패·한도 도달 | 실패/미발견을 구분해 알림. 기록 탐색과 새 질의는 유지하되 같은 질의 한도 우회 호출 금지 [추론] | D-R3-01, D-R3-06 |
| 오프라인 | 검색을 실행하지 않고 연결 없음을 알림. 사용자가 재시도하거나 로컬 기록을 탐색. 검색 요청을 오프라인 대기열에 넣지 않음 | D-R6-03 |

### 화면 배치·문구

- 입력 전 예시는 "the blue puffer at the outdoor stall", "red dress from the second shop", "gray blazer about 20 min ago"를 유지한다. 자리표시 "e.g. the jacket at the blue tarp stall", 입력창의 마이크·보내기 버튼을 유지한다(D-R1-03, D-R7-09).
- 기존 오늘의 가게만 보낸다는 개인정보 안내는 모든 trip·메모 전송을 설명하도록 바꾼다. 최종 영어 문구는 **프로토타입 세션에서 확정**한다(D-R3-03, D-R3-04).
- 단계 이벤트 문구는 "Read your trips", "Narrowed to Shop N", "Searched its photos", "Outlined the items"다. 단계별 상세 내용은 실제 도구 결과만 표시한다. 단계 접힘 요약의 배치·문구와 빈 상태·실패·오프라인 안내는 **프로토타입 세션에서 확정**한다(D-R3-06, D-R3-09).
- 결과 카드의 "Best match" / "Match N", 가게·시각·후보 수와 최상위 후보 윤곽은 유지한다. 다른 trip에서 같은 "Shop N"이 반복될 때의 날짜 표시 배치는 **프로토타입 세션에서 확정**한다(D-R1-03, D-R3-03).
- 직접 탐색은 [All trips](navigation.md) → [Trip의 가게별 사진](capture.md#f-05-trip-화면에-가게-정보-통합) → Pick이다. 다시 묻기·기록 탐색 진입 배치는 **프로토타입 세션에서 확정**한다(D-R3-06, D-R3-10, D-R9-04).
- **프로토타입 초안:** 결과 후 "N photos found · Show steps"/"Hide steps", 상위 3개와 "Show all (N)", 미발견 "No matching photos"·"Ask again"·"Browse your trips", 오프라인 "You’re offline"·"Try again"·"Browse your trips"를 표시한다. 배치·문구는 **프로토타입 화면 세션에서 확정**한다(D-R3-02, D-R3-06, D-R3-09, D-R6-03).

### 실제 구현

- `list_visits({from?,to?,limit?})`는 좌표·이미지 없는 trip/가게 요약을 반환하고 `Shop.note`를 포함한다. `find_photos`는 릴레이가 붙인 512차원 `phraseVector`와 기기 `PhotoEmbedding`의 코사인 유사도로 사진을 찾는다(D-R1-02, D-R3-03, D-R3-04).
- `extract_items`는 `/v1/search/segment`에 최대 3장의 사진과 `concept`를 보내고 Spark에는 후보 수와 최고 점수만 반환한다. 마스크·사진 임베딩은 Spark로 보내지 않는다(D-R3-01; [agent-tools](../contracts/agent-tools.md)).
- 최종 응답은 `final {photoRefs, concept, shopRef?, summary}` 또는 `not_found {reason}`다. 앱은 도구 이름과 실제 수행 상태를 단계 이벤트로 바꾼다(D-R3-06, D-R3-09).

### 프로토타입

- 키워드와 타이머로 검색을 재현한다. 다른 trip("Sat, Oct 24") 사진을 포함한 결과, 상위 3개와 "Show all (N)", 단계 접기/펼치기, 미발견과 All trips 직접 탐색이 있다. 호스트 "Offline"은 제품 UI가 아닌 연결 안내/재시도 시뮬레이션이다. 실제 모든 trip·메모의 Spark 검색이나 API 한도 집행은 아니다(D-R3-01~04, D-R3-06, D-R3-09~10, D-R6-03).

## F-07 음성 질의

- **우선순위:** P0. P1 재논의는 끝났다(D-R0-06, D-R3-05).
- **화면:** "Find it" 입력창의 마이크만 사용한다. 홈 검색창에는 마이크가 없다(D-R3-08 → D-R7-09).
- **동작:** 탭 → 녹음 → 무음 감지 또는 15초 상한에서 자동 종료 → 전사 → 전사문으로 바로 F-06 검색. 전사문은 질의 말풍선에 표시하며 틀렸으면 다시 묻는다. 전사 후 편집·보내기 대기는 없다(D-R3-07).

### 기능 규칙과 상태(확정)

| 상태 | 가능한 동작·제한 | 근거 |
| --- | --- | --- |
| 대기 | Find it의 마이크 탭으로만 시작. 상시 듣기 없음 | D-R3-07, D-R7-09 |
| 녹음 중 | 최대 15초. 무음이면 자동 종료 | D-R3-07 |
| 전사 성공 | 영어 전사문을 말풍선으로 보여 주고 즉시 검색 | D-R0-02, D-R3-07 |
| 무음만 있음·빈 전사·권한 거부·전사 실패 | 빈 질의를 검색하지 않고 다시 입력/녹음할 수 있게 함 [추론]. 실패를 성공 질의로 표시하지 않음 | D-R3-07 |
| 오프라인 | 연결 없음을 알리고 재시도 가능. 음성을 나중에 몰래 전송하는 대기열 없음 | D-R6-03 |

### 화면 배치·문구

- 녹음 중 "Listening…"과 채워진 마이크 상태는 유지한다. 전사 후 수정하라는 기존 토스트는 제거한다. 자동 종료·전사 진행·빈 음성·권한 실패·오프라인의 배치와 새 문구는 **프로토타입 세션에서 확정**한다(D-R1-03, D-R3-07, D-R6-03).
- **프로토타입 초안:** Find it의 "Speak"로 "Listening…"을 시작한다. 배치·문구는 **프로토타입 화면 세션에서 확정**한다(D-R3-07, D-R7-09).

### 실제 구현

- `Voice` 플러그인이 WAV를 반환하고 `/v1/transcribe`를 거쳐 Muse Voice Transcribe로 보낸다. 전사 성공을 F-06의 일반 영어 질의 제출에 연결한다. 무음 판정 세부값은 [device-modules](../contracts/device-modules.md)에서 공유한다(D-R3-07, D-R7-03).
- debug 에뮬레이터 음성 fixture는 intent extra `sf_voice_source=fixture|mic`, `sf_voice_fixture_dir`로 선택한다. `start()`마다 WAV를 실시간 속도로 VAD에 공급해 실제 마이크와 같은 무음 종료 경로를 탄다. fixture 재생 → silence 자동 종료 → `completed` 1회 → 전사·즉시 검색을 E2E 경계로 사용하며 호스트 마이크나 사람 발화를 필수 기준으로 두지 않는다. release에서는 제외하고 화면 표시도 없다. 세부는 [device-modules §8 Voice](../contracts/device-modules.md)를 따른다(D-R3-07, D-R7-10 원칙을 확장한 통합 구현 결정).

### 프로토타입

- Find it에서만 마이크를 제공한다. 약 2초 뒤 자동 종료해 샘플 전사문으로 즉시 검색하며 편집/보내기 대기가 없다. 실제 녹음·VAD·15초 상한·Voice Transcribe 호출은 아니다(D-R3-05, D-R3-07, D-R7-09).

## F-08 옷 후보 선택

- **우선순위:** P0(D-R3-02).
- **화면:** "Pick the item". 쇼핑 사진은 검색 결과·Trip의 가게별 사진 목록·Item의 "Original photo"에서 연다. 별도 Visit은 거치지 않는다. 옷장 입력과 피팅 중 직접 자르기는 같은 분리 기능을 사용하지만 완료 후 돌아갈 목적은 다르다(D-R3-06, D-R4-08, D-R7-08, D-R9-04).
- **동작:** 후보 목록/윤곽을 선택하거나 "Not here? Tap it"으로 탭 분할 → "Use this item" → 저장한 옷/Item. 피팅에서 시작한 직접 자르기는 자동 저장한 뒤 해당 조합으로 돌아간다(D-R3-02, D-R4-08).

### 기능 규칙과 상태(확정)

| 상태 | 가능한 동작·제한 | 근거 |
| --- | --- | --- |
| SAM 후보 있음 | 점수 순 상위 3개만 먼저 표시. 4개 이상이면 "Show all"로 나머지 펼침. 후보 제거 필터 없음 | D-R3-02 |
| 후보 1~2개 | 있는 후보만 표시, 3개를 채우는 가짜 후보 없음 [추론] | D-R3-02 |
| 후보 없음·원본 직접 탐색 | 사진에서 탭해 EdgeTAM 분리 가능. 후보가 없다고 사진을 숨기지 않음 | D-R3-06; research §10 |
| 탭 분할 | 탭 지점에 대한 마스크 3개와 점수를 보여 주고 사용자가 선택. 같은 탭의 영역 대안이며 옷 3벌이 아님 | D-R3-02; research §7.1 |
| 선택 없음·분할 실패 | 완료 버튼 비활성. 다시 탭하거나 원래 후보로 복귀 가능. 실패 시 가짜 마스크를 저장하지 않음 [추론] | D-R3-02 |
| 선택 완료 | `Piece.origin='shop'`, 조각 저장, `walkTo`에 사진 위치 복사. 검색에서 고른 옷은 SAM 개념 이름. 검색 없이 바로 자른 옷은 Spark 이름·종류 작업을 시작하며 대기 중 "Picked item". 사용자 수정 가능 | D-R4-06, D-R5-01, D-R9-02 |
| 사진 삭제 | 사진 단위 삭제 제공. 로컬 원본·임베딩을 삭제하고 그 사진을 다시 열 수 없게 함. 저장한 옷의 조각/목적지는 유지. trip 삭제는 All trips/Trip 흐름 | D-R3-11 |
| 오프라인 | 기존 사진 탐색·기기 EdgeTAM·선택 저장·삭제 가능. 새 SAM 검색은 연결 안내/재시도 | D-R6-03 |

### 화면 배치·문구

- 원래 비율 사진, 번호와 윤곽, 선택 바깥 어둡게 표시, 목록의 썸네일·이름·점수와 "Found N items, best first"를 유지한다. 접힌 목록과 사진 윤곽의 상위 3개 표시 및 "Show all" 위치는 **프로토타입 세션에서 확정**한다(D-R1-03, D-R3-02).
- "Not here? Tap it", "Use this item", "Tap the item in the photo", "Which area?", "Show matches"는 유지한다. 탭 마스크 이름 "Small area", "Medium area", "Large area"는 실제 영역 크기를 설명하는 표시이며 점수 순위를 크기 순서로 바꾸지 않는다(D-R1-03, D-R3-02).
- 쇼핑 사진 상단 내려받기 아이콘의 접근성 이름 "Save to gallery", 완료 "Saved to gallery · location removed"는 유지한다. 옷장 입력에는 이 내려받기가 없다(D-R2-09, D-R2-11).
- 사진 삭제의 위치·확인·삭제 후 복귀, 실패/빈 상태, 직접 선택의 이름 편집, 피팅 복귀 배치는 **프로토타입 세션에서 확정**한다. 검색 없이 바로 자른 옷은 이름 처리 대기 중 "Picked item"으로 보이며, 오프라인이면 이름 작업을 대기열에 넣는다(D-R3-11, D-R4-08, D-R9-02).
- **프로토타입 초안:** 부제는 "Shop · trip date · time" 맥락을 표시한다. "Delete photo"는 확인 시트를 열고, 피팅용 완료는 "Add to outfit", 옷장용 완료는 "Add to wardrobe"다. 새 문구·배치는 **프로토타입 화면 세션에서 확정**한다(D-R3-03, D-R3-11, D-R4-08).

### 실제 구현

- SAM 3.1 마스크와 기기 EdgeTAM 마스크는 박스가 아니라 윤곽이다. PE-Core는 사진 검색에만 사용하고 후보 필터로 사용하지 않는다(D-R3-02; research §7.1).
- 사진 내려받기는 앱 원본을 남긴 채 EXIF GPS를 제거한 복사본을 갤러리에 저장한다. 삭제 연쇄와 파일 수명은 [data-model](../contracts/data-model.md)을 따른다(D-R2-05, D-R2-11, D-R3-11).
- 검색 없이 trip에서 바로 자른 가게 옷도 `/v1/describe/piece`에 잘라낸 이미지만 보내 Spark가 이름·종류를 붙인다. 원본 trip 사진을 이름 붙이기용으로 보내지 않는다. 오프라인은 `label_piece` 대기열로 재연결 후 처리한다(D-R9-02).

### 프로토타입

- 검색 진입에는 SAM 후보를 흉내 낸 고정 박스, 탭 모드에는 사각형 마스크 대안이 있다. "Not here? Tap it"/"Show matches"로 전환하며 상위 3개/"Show all"과 사진 삭제 확인을 제공한다. 직접 자른 옷은 "Picked item"으로 저장한 뒤 타이머로 이름을 붙이고 오프라인이면 대기한다. `mode: outfit`은 "Add to outfit"으로 저장 후 Try on에 복귀한다. 내려받기는 위치 제거 토스트만 있고 실제 파일/EXIF 처리는 없다(D-R3-02, D-R3-11, D-R4-08, D-R6-03, D-R9-02).
