# 매장까지 도보 길 안내

상태: 인터뷰 R9까지 반영, 화면 배치는 프로토타입 세션에서 확정

근거: [decisions.md](../decisions.md) D-R5-01~05, D-R6-03. 관련 계약: [data-model](../contracts/data-model.md), [device-modules](../contracts/device-modules.md), [relay-api](../contracts/relay-api.md), [데이터 경계](../product/privacy.md).
R9 추가 근거: D-R9-03(결과 목적지 스냅샷), D-R9-04(Item/Result 전용 진입, Visit 제거).

## F-15 매장까지 도보 길 안내

- **우선순위:** P0(D-R5-01).
- **화면:** "Walk back", 전체 화면 지도(D-R1-03).
- **동작:** 옷의 촬영 위치로 경로 요청 → 경로선·턴바이턴 → 이탈 시 재탐색 → 끝 구간 방향·직선 거리 → 사용자가 가게 확인 후 종료(D-R0-03, D-R5-01, D-R5-04).

### 기능 규칙과 상태(확정)

| 상태 | 가능한 동작·제한 | 근거 |
| --- | --- | --- |
| Item에서 진입 | 길 안내 진입점은 Item과 Result뿐. Item 목적지는 저장한 옷의 `Piece.walkTo`이며 `Shop.spot`이 아님. 핀 이동 금지 | D-R5-01, D-R5-02, D-R9-04 |
| Result에서 진입 | 결과 생성 시 복사한 대상 옷의 길 안내 위치 사용. 원래 대상 Piece 삭제 후에도 결과 보기·길 안내 유지. 동반 옷 순서·가게 수로 목적지 변경 금지 | D-R5-03, D-R9-03 |
| trip 삭제 후 진입 | 저장한 Piece의 조각·`walkTo`가 남으므로 안내 가능. 원본 사진 연결은 사라짐 | D-R3-11, D-R5-01 |
| 경로 있음 | 지도 경로선·다음 턴·남은 거리/시간. 거리와 무관하게 앱 안 도보 안내, 외부 지도 앱으로 넘기지 않음 | D-R5-04, D-R5-05 |
| 경로 이탈 | 새 현재 위치와 같은 목적지로 재탐색. 목적지 핀은 이동하지 않음 | D-R5-02, D-R5-04; research §9 |
| 목적지 근처·경로 데이터 없는 구간 | 방향 화살표와 직선 거리로 전환. 경로 데이터 없음과 네트워크 실패를 같은 성공 상태로 위장하지 않음 | D-R5-04, D-R6-03 |
| 도착·외관 있음 | 외관 사진과 설명으로 사용자가 직접 확인. GPS 핀 진입만으로 정확한 가게라고 단정하지 않음 | D-R0-03 |
| 도착·외관 없음 | 메모와 핀 반경을 보여 주는 도착 카드 [추론]. 메모까지 없으면 없는 정보는 지어내지 않음 | D-R2-07, D-R5-04 |
| 오프라인·경로 요청 실패 | 연결/요청 실패를 알리고 재시도 제공. 오프라인 안내 가능하다고 보장하거나 자동 대기열에 넣지 않음 | D-R6-03 |
| 현재 위치 없음·권한 없음 | 현재 위치 기반 턴/방향/거리 계산 불가를 표시하고 재시도 가능 [추론]. 가짜 현재 위치나 거리 표시 금지 | D-R5-01, D-R5-04 |
| 유효한 옷 촬영 위치 없음 | 안내를 시작하지 않음. Trip·가게 영역·Pick에서 직접 안내하는 별도 진입은 제공하지 않음 | D-R5-01, D-R9-04 |

### 화면 배치·문구

- 지도에는 경로선·지나온 구간(점선)·현재 위치·목적지 핀/반경을 유지한다. 상단은 방향 아이콘·다음 안내 거리·실제 경로의 안내 문장이다. 고정 예시 안내를 실시간 경로처럼 쓰지 않는다(D-R1-03, D-R5-04).
- 하단의 외관 썸네일·"Shop N"·남은 거리/시간·"where you took the photo"·"End"는 유효한 정보가 있을 때 유지한다. 이탈 안내 "Off route. Finding a new way…"도 유지한다(D-R1-03, D-R5-01).
- 외관 있는 도착 카드의 "You're at Shop N", "Look for this shop front. Stalls here sit close together, so trust the photo over the pin.", 외관 사진·설명·"Done"은 유지한다. GPS 오차를 이유로 핀 수정을 제공하지 않는다(D-R0-03, D-R5-02).
- 끝 구간 화살표·직선 거리, 외관 없는 가게의 메모/핀 반경 도착 카드 [추론], 오프라인·실패·위치 없음·원본/trip 삭제 후 목적지 카드의 배치·새 문구는 **프로토타입 세션에서 확정**한다(D-R3-11, D-R5-04, D-R6-03).

### 실제 구현

- 지도는 WebView MapLibre GL JS + OpenFreeMap 직접 타일 요청이다. 앱은 출발·도착을 `/v1/route`에 보내고 로컬 Mac 릴레이가 FOSSGIS OSRM foot을 호출한다. Spark/Meta에는 경로 좌표를 보내지 않는다(D-R6-05, D-R7-03; research §8.2).
- Item은 저장 시 사진 위치를 복사한 `Piece.walkTo`, Result는 생성 시 독립 복사한 대상 옷의 위치 스냅샷을 사용한다. 원래 Piece가 삭제됐다고 결과 안내를 차단하거나 다른 가게 좌표로 바꾸지 않는다. 스냅샷 필드는 [data-model](../contracts/data-model.md)을 따른다(D-R3-11, D-R5-01, D-R9-03).
- JS가 경로·이탈 감지·끝 구간 방향/거리 계산을 맡고 Capacitor Geolocation으로 현재 위치를 받는다. 전환 임계값과 위치 정확도 처리는 [device-modules](../contracts/device-modules.md)을 따른다. 음성·백그라운드·실내 안내는 제외한다(D-R5-04, D-R7-03; research §9).

### 프로토타입

- 지도는 고정 SVG이고 4단계 안내·거리도 고정값이다. "Demo"의 "Walk a step"과 "Go off route"는 시연용이며 제품 UI가 아니다(D-R1-03).
- 현재 외관 없는 가게는 자리표시를 쓰고 실제 끝 구간·오프라인·목적지 검증은 없다. 새 메모/핀 반경 도착 카드와 촬영 위치 기반 목적지는 **프로토타입 미반영**이다(D-R5-01, D-R5-04, D-R6-03).
