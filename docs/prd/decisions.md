# 인터뷰 결정 로그

작성 시작: 2026년 11월 4일
상태: R0~R10 확정. 화면 배치와 문구는 프로토타입 세션에서 이어서 정한다

이 문서는 PRD 인터뷰에서 사용자와 합의한 결정만 기록한다. 결정마다 ID를 붙이고, 다른 PRD 문서는 이 ID로 근거를 가리킨다. 기존 문서(`street-fitting-spec.md` 이관본인 `ux/`, `street-fitting-research.md` 9장)와 다른 결정은 "이전 문서와의 관계"에 적는다.

## R2 (11월 4일): 쇼핑 모드, 촬영, 가게 구분

| ID | 항목 | 결정 | 이전 문서와의 관계 |
| --- | --- | --- | --- |
| D-R2-01 | 알림 카드 구성 | 쇼핑 모드 동안 알림 카드 하나를 계속 띄운다. 내용은 상태 줄("Shop N · N photos · N min")과 액션 2개다. "Take photo"는 앱 카메라를 연다. "New shop"은 카메라를 열면서 새 가게를 시작한다(D-R2-07과 같은 동작). 카드 본문을 누르면 앱 홈이 열린다. "End" 액션과 썸네일은 넣지 않는다 | D-R0-04 구체화 |
| D-R2-02 | 유도 알림 | 상시 카드 말고는 알림을 보내지 않는다. 헤즈업, 체류 알림, 종료 요약, 장시간 리마인드 모두 없다 | 새 결정 |
| D-R2-03 | 가게 구분 | 사용자가 "New shop"으로 직접 나누는 방식만 쓴다. 사진 묶음과 이동 거리로 자동 판단하는 기능은 MVP에서 뺀다 | research 9장 P0 "자동 구분"을 제외로 바꿈 |
| D-R2-04 | 외관 묘사 | 외관 사진은 건너뛸 수 있다. 묘사는 뒤에서 처리하고, 카메라 화면에 묘사 카드를 띄우지 않는다. 묘사 결과는 가게 화면 등 묘사를 쓰는 화면에만 나타난다 | 기존 F-04 카메라 알림 카드를 없앰 |
| D-R2-05 | 사진 저장 위치 | 앱에서 찍은 사진은 앱 전용 저장소에만 저장한다. 갤러리 저장은 사용자가 고를 때만 한다. 갤러리에 불필요한 사진이 쌓이지 않게 하려는 것이다 | 새 결정 |
| D-R2-06 | Mock 글래스 | DAT Mock 글래스 캡처는 제외한다 | research 9장 P1을 제외로 바꿈 |
| D-R2-07 | "New shop" 동작 | 누르면 사용자 입력 없이 현재 좌표를 새 가게 위치로 저장한다. 외관 사진과 메모는 원할 때만 추가한다. 카메라 위 배너에서 바로 추가하거나 나중에 가게 화면에서 추가한다. "In a new shop?" 시트는 없앤다 | 기존 F-03 시트 흐름을 대체 |
| D-R2-08 | 가게 메모 | 가게마다 사용자가 짧은 메모를 붙일 수 있다. 메모를 에이전트 방문 요약에 넣을지는 R3에서 정한다 | research 9장 제외 항목 "짧은 메모"를 다시 넣음 |
| D-R2-09 | 갤러리 연결 | 앱에서 새로 생긴 사진은 앱에만 저장하고, 사용자가 나중에 사진별로 갤러리에 내려받을 수 있다. 갤러리에서 앱으로 올리기는 보유 옷(옷장)에만 허용한다. 쇼핑 사진을 갤러리에서 가져오는 기능은 뺀다 | research 9장 P0 "사진 가져오기"를 제외로 바꿈 |
| D-R2-10 | 위치 권한 거부 | 쇼핑 모드를 시작하지 않는다. 시트로 이유를 설명하고 "Open settings"를 보여 준다 | 새 결정 |
| D-R2-11 | 기본 동작 | 알림 권한을 거부해도 쇼핑 모드는 시작하고, 알림 카드가 없다는 토스트를 한 번 띄운다. 최근 앱 목록에서 앱을 지워도 포그라운드 서비스는 기록을 계속하고, 앱을 다시 열면 기록 중 상태로 돌아온다. 갤러리로 내려받을 때는 위치 정보(EXIF GPS)를 빼고 저장한다 | R2 제안 기본값을 사용자가 R10에서 확정 |
