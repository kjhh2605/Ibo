1쇼핑 모드와 촬영

쇼핑 모드를 켜면 새 trip과 Shop 1이 생긴다. 위치 권한은 필수, 알림은 선택. 카메라에서 옷을 찍고 "New shop"으로 가게를 나누며, 외관 사진과 메모는 선택이다. 상태 표시줄을 내리면 알림 카드에서 바로 촬영할 수 있다.

근거: D-R2-01~11, D-R3-03, D-R6-03

2기록 탐색: All trips → Trip

홈에는 최근 trip 하나와 "All trips"가 있다. 별도 가게(Visit) 화면 없이 Trip 한 화면에 가게별 외관·묘사·메모·사진이 모인다. Trip에는 길 안내가 없고 trip 삭제를 제공한다. 오프라인이면 외관 묘사는 대기열에서 기다린다.

근거: D-R3-03, D-R3-10, D-R3-11, D-R6-03, D-R9-04

3검색: Find it → 후보 → Pick → Item

모든 trip을 대상으로 영어 질의(입력 또는 음성)로 찾는다. 음성은 말이 끝나면 자동으로 멈추고 바로 검색한다. 진행 단계는 결과가 나오면 한 줄로 접히고, 후보는 상위 3개 + "Show all". 못 찾으면 다시 묻거나 trip을 직접 둘러본다.

근거: D-R3-01~09, D-R7-09, D-R4-06, D-R3-11

4가상 피팅: 대상 1벌 + 함께 입을 옷 최대 5벌

가게 옷만 피팅 대상이 된다. 함께 입을 옷은 저장한 옷, 옷장, trip 사진에서 바로 자른 옷에서 고른다(최대 5벌). 본인 사진은 1장이고 얼굴·머리 마스킹은 기기에서 자동으로 한다. 전송 확인 화면 없이 이 화면에서 바로 생성한다.

근거: D-R4-01~11, D-R9-01~03

5길 안내: 옷을 찍은 자리로

목적지는 옷 사진을 찍은 위치이고 핀은 옮길 수 없다. Item과 피팅 결과에서만 시작한다. 경로가 끝나면 마지막 구간은 방향과 직선 거리로 안내하고, 도착 카드는 외관 사진이 없으면 메모·설명으로 대신한다. 거리와 관계없이 앱 안에서 안내한다.

근거: D-R5-01~05, D-R6-03, D-R9-03, D-R9-04

6옷장과 개인정보 안내

옷장은 내 옷을 갤러리나 촬영으로 추가하고 Spark가 이름을 붙인다(수정 가능). 옷장 옷은 함께 입을 옷으로만 쓰고 단독 피팅 대상이 아니다. Privacy는 기기 밖으로 나가는 데이터의 경계를 보여 준다.

근거: D-R4-06, D-R4-09, D-R3-11, D-R7-08

7빈 상태와 예외

기록이 없거나, 오프라인이거나, 모두 지웠을 때의 화면. 로컬 데이터는 오프라인에도 그대로 보이고, 네트워크가 필요한 일만 기다리거나 막힌다.

근거: D-R3-11, D-R6-03, D-R9-02
